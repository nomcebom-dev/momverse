# MomVerse

MomVerse is a personal interactive web experience I built as a birthday gift for my mom.

Instead of doing something simple like a message or card, I wanted to create something more meaningful and memorable. The idea was to build a small “world” that she could go through, with different scenes, animations and moments.

---

## Project Idea

This project is based on storytelling through interaction.

The user scrolls through different sections, and each part reveals something new — like memories, messages or small interactive elements. The goal was to make it feel emotional and personal, not just technical.

---

## Features

- Animated starfield background using Canvas  
- Scroll-based storytelling (content reveals as you move down)  
- Interactive elements (e.g. candles, transitions between scenes)  
- Background audio with smooth transitions  
- Personal voice/message integration  
- Multi-section layout with a narrative flow  

---

## Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- Canvas API  
- Web Audio API  

---

## What I Learned

While building this project, I learned:

- How to use the Canvas API to create animations  
- Working with audio in the browser  
- Structuring a project around user experience, not just features  
- Controlling animations and timing using JavaScript  
- Paying attention to small details (transitions, flow, feel)

---

## Challenges

Some challenges I faced:

- Getting the animations to feel smooth and not distracting  
- Syncing audio with user interaction  
- Making everything work together (scroll + animation + sound)  
- Debugging small issues that affected the overall experience  

A lot of this project was trial and error.
